# 评估结果（阶段 0，2026-10-11，M4 16GB）

所有数字都可以用仓库里的命令复现，数据放在 `data/`（不纳入 git）。

## 1. 转录（音频 → 音符）

命令：`m2s eval-maestro --n 15 --crop 90`。取 MAESTRO v3 测试集 15 首，每首截取前 90 秒，用 mir_eval 计算，onset 容差 50 ms。

| 指标 | Transkun V2（MPS） |
|---|---|
| Note onset F1 | **0.983** |
| Note onset + offset F1 | **0.844** |
| 速度 | 实时率约 0.08（3 分钟的曲子约 15 秒） |

逐曲结果中最低的是 Liszt《Wilde Jagd》，F1 0.923，原因是召回率只有 0.865（快速八度和密集和弦）。基线对比见 ADR 0002：basic-pitch 的 F1 为 0.72。

## 2. 记谱（音符 → 乐谱）

命令：`m2s eval-asap`。用 ASAP 的 228 首双谱表钢琴乐谱，各取前 64 小节，加入速度漂移 ±10%、onset 抖动 σ = 15 ms，并随机丢弃 30% 的 downbeat，合成为演奏；再交给 S3–S6，与原谱逐项比较。

这个评估把量化、拍号、分手、调号与转录误差隔离开，单独衡量这几步。

| 指标 | 初版基线 | 当前版本 |
|---|---|---|
| Onset 精确率（中位数 / 平均） | 0.962 / 0.717 | **0.965** / 0.714 |
| 谱表（左右手）准确率，平均 | 0.871 | **0.898**（中位数 0.918） |
| 拍号正确率 | 77.2% | **77.6%** |
| 调号正确率 | 68.4% | **82.0%** |
| 弱起正确率 | 77.2% | 76.8% |
| MusicXML 通过严格校验 | 100% | **100%** |

Onset 平均值远低于中位数，原因是少数乐谱整首失配：拍单位有歧义（如 2/2 ↔ 2/4、3/8 ↔ 3/4），音符位置的 tick 尺度不同，无法逐个比较。这些情况用户填写拍号先验参数即可解决。

分项改进的依据：
- 调号：Temperley 调性轮廓 + 首尾加权（ADR 0004）。
- 拍号：简单拍 / 复合拍模型选择（ADR 0004）。
- 谱表：piano_svsep 精修（ADR 0003）。在标准答案的量化音符上，平均从 0.886 提升到 0.928。

## 5. 回归门限

`pytest -m slow tests/regression`：固定的 40 首 ASAP 子集，使用启发式分手，门限见 `tests/regression/thresholds.json`。任何改动都不应让这些指标低于门限。

## 6. 2026-10-24 调查结论与下一步

数据来自用户的两首 YouTube 曲（Animenz 钢琴改编），详见 ADR 0005。

**音高基本没错**：Call of Silence 有 99.7% 的音落在 A 大调内；转录结果与音频的色度相似度为 0.89，对照组（移调后）约 0.71。

**乐谱看起来乱，主要原因有三个**：
1. 节拍追踪在曲中切换速度层级。
2. 量化网格把快速音型写成六连音。
3. 踏板下的「手指松开时值」产生大量休止符。

其中第 2、3 项已修复。

**按优先级排的下一步**：
1. **真实音频评估**：18 段 MAESTRO/ASAP 录音上，位置 + 音高的准确率为 0.70。损失主要来自量化（约 18 个百分点）和节拍（约 10 个百分点），不是转录。
2. **节拍 DP**：基于速度连续性；编辑器加「速度 ×2 / ÷2」按钮。
3. **量化器改进**：鼓励重复的节奏型；识别琶音和装饰音。之后可以考虑自训练一个以节拍为条件的 seq2seq 模型。
4. **分段先验与局部重算**：可以按段落设先验参数，只重算选中的小节。
5. **可读性**：加 8va 记号、自动换谱号、精简踏板记号。已完成，并加了「原样 / 易读 / 简化」三个级别，新任务默认「易读」，见 ADR 0007。
6. **转录**：维持 Transkun；只在劣化音频（混响、压缩等）上的评估证明有必要时，再做幽灵音过滤。
